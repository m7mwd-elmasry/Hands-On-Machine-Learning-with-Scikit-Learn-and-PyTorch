# Hands-On Machine Learning with Scikit-Learn and PyTorch

My practical implementations and projects while studying **Hands-On Machine Learning with Scikit-Learn and PyTorch** by Aurélien Géron.

This repository focuses on applying Machine Learning concepts through hands-on coding, experiments, and end-to-end projects.

- Data preprocessing.
